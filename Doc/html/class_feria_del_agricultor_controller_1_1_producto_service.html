Detailed Description

Servicio encargado de cargar y administrar productos disponibles.

Lee y escribe desde: [BaseDirectory]\Data\Productos.csv

Formato esperado (separado por ';'): Productor;NombreProducto;Precio;Cantidad;UnidadMedida

IMPORTANTE:

  • "Productor" en el CSV debe contener el NOMBRE DEL PUESTO (NombrePuesto), para hacer match con Productor.NombrePuesto (de Productores.csv).
  • UnidadMedida admite: Unidades, Kilogramos, Litros (y también Kg/Kilos/Litro/Litros).
