Detailed Description

Proporciona operaciones para cargar, consultar y filtrar los puntos de feria, a partir de un archivo CSV o, en su defecto, mediante datos de respaldo.

◆ PuntoFeriaService()

FeriaDelAgricultorController.PuntoFeriaService.PuntoFeriaService ( string rutaCsv = null)

Inicializa el servicio y carga los puntos de feria desde un archivo CSV. Si no se proporciona ruta, se utiliza la ruta por defecto [BaseDirectory]\Data\PuntosFeria.csv. Si no se logra cargar información, se emplean datos de respaldo.

Parameters
rutaCsvRepresenta la ruta del archivo CSV a utilizar. Si es nula o vacía, se usa la ruta por defecto.
